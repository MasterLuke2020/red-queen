# Red Queen 1.0.0-rc1 — Dokumentationspaket

Dieses Paket ist der eingefrorene Referenzstand zur **live verifizierten** ersten Release-Candidate-Version von Red Queen.

Die Produkt-/Referenzdokumentation ist überwiegend auf Englisch gehalten, damit sie später direkt als Grundlage für ein öffentliches Repository dienen kann. Der technische Handover unter `handover/` ist bewusst auf Deutsch und enthält den aktuellen Projektzustand für die direkte Fortsetzung der Entwicklung.

Wichtig: `wnhf` bleibt die technische Home-Assistant-Domain. Der öffentliche Name des Frameworks ist **Red Queen**.
