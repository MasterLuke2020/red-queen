# Security Policy

## Supported release line

During the release-candidate phase, security fixes are evaluated against the current Red Queen `1.0.0-rc*` line. A runtime-affecting fix creates a new release candidate and is not silently applied to an already verified artifact.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in a public issue.

For the private repository, contact the repository owner directly. Before the repository is made public, enable GitHub Private Vulnerability Reporting / Security Advisories and use that channel for security reports.
