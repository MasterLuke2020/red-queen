# Red Queen 1.0.0

Red Queen is a semantic home framework for Home Assistant. The public product name is
**Red Queen**; the technical Home Assistant domain remains **`wnhf`**.

## Stable identity

- Version: `1.0.0`
- Channel: `stable`
- Phase: `stable`
- Release-candidate label: none
- WNHF `1.40.0` / `WP-4.7.20.0`
- Canonical execution API: `1.0`
- Canonical real-execution contract: `2.3-rc11`

The managed configurator, native entities, `/red-queen` dashboard, diagnostics,
controlled manual → managed adoption, guided repair and guarded canonical physical
execution are promoted from the qualified RC14 baseline. `garage.stop` remains guarded
canonical execution.

Stable qualification is in progress. No new feature domain belongs in this phase.

See `docs/STABLE_1_0_VALIDATION.md` and `docs/RELEASE_NOTES_1.0.0.md`.
