# Red Queen 1.0.0-rc14 — Development Notes

RC14 is the controlled migration and repair hardening release on the path to stable
Red Queen 1.0.0.

Development identity:

- Red Queen `1.0.0-rc14`
- WNHF `1.40.0`
- `WP-4.7.20.0`
- Canonical execution API `1.0`
- Canonical real-execution contract `2.3-rc11`

## Planned scope

RC14 is intentionally bounded to installation migration/repair quality.

The first work package introduces a read-only migration/repair preview for existing
manual or damaged configuration. Later RC14 work may add explicit repair/migration
transactions only after preview and user confirmation.

Non-goals before stable 1.0:

- climate semantics;
- media expansion;
- large Plant Care feature additions;
- new physical execution actions;
- automatic takeover of manual registries.

This file describes an active development candidate. Exact-package qualification and
publication status will be recorded only after RC14 feature freeze.
